Probed infrastructure — honest node health

There is no public full-node-list API for BCH (no Bitnodes equivalent; Coin Dance publishes HTML only). This dashboard does not claim a global BCH full-node census. It probes the public Electrum/Fulcrum servers below for liveness, height vs. tip, and round-trip latency.
